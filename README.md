# 🚗 DVLD - Driver & Vehicle Licensing Department

A comprehensive desktop management system designed to automate and streamline driver licensing, application processing, driving tests, license renewals, replacements, and license detention workflows.

---

## 🛠️ Tech Stack & Architecture

- Language: C# (.NET)
- UI Framework: Windows Forms (WinForms)
- Database: Microsoft SQL Server
- Data Access: ADO.NET
- Architecture Pattern: 3-Tier Architecture (Presentation Layer, Business Layer, Data Access Layer)

---

## ⚙️ Setup & Installation

### 1️⃣ Database Setup
1. Open SQL Server Management Studio (SSMS).
2. Execute the script located at database/schema.sql to generate the database tables, relationships, and stored procedures.
3. *(Optional)* Execute database/seed_data.sql to insert initial test data.
